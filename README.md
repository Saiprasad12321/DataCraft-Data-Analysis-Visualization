# DataCraft: Consumer Behavior & Shopping Analytics

A data analytics project focused on understanding customer shopping and purchasing behavior using Python, MySQL, and Power BI.

## 📌 Project Overview

The dataset contains **3,900 customer purchase records** with **18 customer and transaction-related attributes**.

The project focuses on analyzing:

* Customer spending patterns
* Purchase frequency
* Discount usage
* Subscription behavior
* Customer demographics
* Shipping preferences

## 🛠 Tools Used

* **Python:** Pandas, NumPy, Matplotlib, Seaborn
* **MySQL:** Data storage and SQL analysis
* **Power BI:** Dashboard and data visualization

## 📊 Analysis Workflow

### 1. Data Cleaning & EDA — Python

* Checked the dataset for missing values and inconsistencies.
* Handled missing values in the `Review Rating` column.
* Checked and corrected data types.
* Explored customer and purchasing patterns using Python.

### 2. SQL Analysis — MySQL

* Analyzed customer spending and purchase amounts.
* Compared subscribers and non-subscribers.
* Studied the relationship between discount usage and purchase amounts.
* Analyzed purchase frequency across customer groups.
* Examined customer preferences using demographic and transaction data.

### 3. Dashboard — Power BI

Created an interactive dashboard to visualize:

* Customer spending
* Purchase frequency
* Subscription status
* Discount usage
* Customer demographics
* Shipping method preferences

## 💡 Key Takeaways

The analysis helped identify differences in purchasing behavior across customer groups and provided a clearer view of spending, subscription, discount, and shipping patterns.
